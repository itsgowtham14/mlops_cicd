Pipeline Architecture

Automated CI/CD Workflow Stages

Triggered on every push to main branch using GitHub Actions.

1 CI Stage
Environment Setup
Checkout repo code, set up Python 3.11, cache & install dependencies from requirements.txt.
2 CI Stage
Model Training & Eval
Executes model.py, performs stratified split, fits Random Forest, saves metrics.json.
3 CI Stage
PyTest Verification
Runs automated test suite in test_model.py; ensures 100% test pass rate before deployment.
4 CI Stage
Artifact Archival
Uploads validated metrics.json as a GitHub Actions build artifact.
5 CD Stage
GitHub Pages Deploy
Runs on needs: CI (skipped if CI fails). Downloads real metrics artifact and deploys dashboard.
